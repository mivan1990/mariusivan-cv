# CV Interactiv Modern — Hub

Proiect separat: construirea unui **CV interactiv modern** de la zero, într-un repo nou.
Repo-ul actual `mariusivan-portfolio` rămâne neatins și funcțional.

## Structura proiectului

- [[01-Conținut-CV]] — conținut real, bilingv EN/RO (sursă: `About.tsx`)
- [[02-Proiecte]] — cele 3 proiecte de prezentat
- [[03-Stack-Și-Componente]] — decizii tehnice stabilite
- [[04-Deploy]] — planul de lansare pe subdomeniu
- [[05-Plan-Execuție]] — pași de execuție, în ordine
- [[06-Log]] — jurnal de progres
- [[07-Handover]] — document de preluare (actualizat la fiecare sesiune)
- [[08-Componente]] — lista completă de componente folosite
- [[09-Design]] — cum arată site-ul, de la sus la jos
- [[10-Research]] — ce putem lua de la alți site-uri de genul
- [[11-Taskuri]] — taskuri de la A la Z (A = proiect gol, Z = ready to deploy)

## Rezumat

| Aspect | Decizie |
|---|---|
| Obiectiv | CV interactiv modern, repo nou, de la zero |
| Stack | React 18 + TypeScript + Vite + Tailwind + shadcn/ui |
| Componente | shadcn/ui ca bază + 2-3 piese spectaculoase din 21st.dev |
| Limbi | EN/RO cu toggle |
| Deploy | SWAP pe subdomeniu: `mariusivan.ro` = CV nou, `xp.mariusivan.ro` = XP |
| Repo actual | Neatins, rămâne live |
